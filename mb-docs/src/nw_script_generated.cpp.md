# nw_script_generated.cpp —— 构建时生成的 JS 内置副本（勿手改）

- 源文件：[nw_script_generated.cpp](../../generated/nw_script_generated.cpp)（约 88KB）
- 性质：**自动生成产物，不要手工编辑。** 修改页面逻辑请改 [js/api/\*.js](../../js/api/) 或 [nw_node.js](../../js/nw_node.js)，然后跑 [build-nw.bat](../../build-nw.bat)（它先调 [tools/embed-js.ps1](../build/embed-js.ps1.md) 重新生成本文件）。

## 内容形状

- 文件首行：`// Generated by tools/embed-js.ps1 -- do not edit.`
- `#include "nw_script.h"`，命名空间内实现两个函数：
  - `BuiltinApiScript()`：把 api\*.js **按文件名排序拼接**、外层包统一 IIFE（`__nmbInstalled` 幂等守卫）后的完整文本；每段形如 `R"NWJS(...)NWJS",`，每片不超过 8000 字符（避开 MSVC C2026 的 16380 字节截断），运行时把各片 `+=` 拼回整串；
  - `BuiltinNodeScript()`：nw_node.js 全文，同样切片。

## 与运行时的一致性要求

嵌入版与"exe 旁边磁盘版"必须行为一致：
- 拼接顺序（按文件名排序）、IIFE prologue/epilogue 与 [nw_host.cpp](../../src/nw_host.cpp) 里的
  `kApiPrologue/kApiEpilogue`、`AssembleApiModules()` 保持逐字节相同的包装（embed-js.ps1 注释强调漂移会让两条路径行为分叉）；
- 每个模块前插入 `// ---- <文件名> ----` 注释行，页面报错时能指认是哪个模块。

## 何时真的会被用到

仅当 exe 旁边没有 `api\` 目录或缺 `nw_node.js` 时，`Host::LoadScripts()` 才回落到这两个内置函数；正常开发/分发（build-nw.bat 会 xcopy JS 到 bin\api\）走的是磁盘版。

# tests/ —— 端到端测试体系总览

- 目录：[tests/](../../tests/)
- 原则（读每个测试前先记住）：这些测试都在**真实的 bin\nw.exe 进程**里跑，不 mock 内核。
  很多证据页面自己拿不到（标题栏文字、窗口父子关系），所以刻意从**进程外部**取证。

## 三套测试应用 + 六个驱动脚本

| 被测应用 | 驱动脚本 | 外部探针 | 验证什么 |
|---|---|---|---|
| [smoke/](app-smoke.md)（含原生 Node 可选入口探测） | [run-smoke.bat](run-smoke.bat.md) | 落盘 JSON 报告 | 整条桥：nw.* 注入、node 桥、fs 落盘、Screen/Window/Clipboard、同步通道、Window.open 异步结算、mbQuery 异步应答 |
| [title/](app-title.md)（标题链路） | [run-title.bat](run-title.bat.md) | `tasklist /v` 每秒采样窗口标题 + stderr 页面日志 | setTitle 覆盖值生效、document.title 不能反超、导航后覆盖值清除 |

## 统一约定

- 所有 .bat / .ps1 **纯 ASCII**：cmd 按 OEM 码页（936）读 .bat、PS 5.1 按 GBK 读无 BOM .ps1，
  非 ASCII 会直接破坏解析。中文只出现在 .html / .md 里。
- 驱动脚本都 `cd /d "%~dp0.."` 回到 `nw\`，用相对路径 `bin\nw.exe --nwapp=tests\xxx`；
  bin\nw.exe 不在则退出码 1（先跑 [build-nw.bat](../build/build-nw.bat.md)）。
- 自动化防挂死：启动一律带 `--nw-no-dialog`（或应用自退），启动失败不弹模态框；
  超时/收尾都 `taskkill /im nw.exe /f`。
- 退出码约定（各 runner）：`0`=PASS，`1`=环境缺失（没编译），`2`=超时/无窗口，`3/4`=断言失败。

## 已验证状态（背景）

loopback 主通道落地后，smoke 连跑 25 轮、title 5 轮、window 5 轮全绿；
安全项实测：错令牌 403、仅 127.0.0.1 监听。这些测试的价值就是把"通道偶发失败"这类
随机问题变成可重复复跑的回归。
